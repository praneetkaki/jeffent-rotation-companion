# JeffENT Rotation Companion — faculty one-pager

*A student-built, faculty-vetted study tool for the Otolaryngology rotation.*

## The problem
Students rotating through ENT face a broad, high-stakes clinical scope (exam skills, emergencies, referral red flags, common differentials) with limited rotation-specific, active-recall study material. Passive review documents don't build durable recall.

## The proposal
A free, open, **active-recall + spaced-repetition** web tool scoped to the *clinical essentials* of the ENT rotation. Content is authored by students, **vetted module-by-module by JeffENT faculty**, and maintained as a living asset passed to each incoming class. It is deliberately lightweight — a static web app with no server, no patient data, and no cost to run.

## Why it's academically credible
- **Anchored to published curricula.** Each module maps to the **AAO-HNS Otolaryngology Core Curriculum** and the program's chosen **Delphi priority list** of essential topics, giving content validity.
- **Faculty co-authorship is built into the workflow.** Every card, case, and diagram ships as *DRAFT — pending faculty review*; a reviewer signs off item by item. Faculty vetting is the design, not a courtesy.
- **Evidence-based format.** Active recall and spaced repetition are well-supported for retention, and the model mirrors validated ENT-education tools (e.g., Headmirror's OtoRecall).

## Instrumenting it for scholarship (the study)
The same rollout that helps students generates a presentable abstract/publication and a durable leadership artifact:

1. **Pre-test** (baseline knowledge) → **tool use over the rotation** → **post-test** (same or matched items).
2. **Satisfaction/usability survey** at the end.
3. Report knowledge gain and acceptability — the design every comparable published med-ed tool used to show effectiveness.

Measurement will run through a simple survey platform (e.g., Google Forms) capturing an anonymous session id only — **no identifiable data in the tool.** IRB/education-exemption review to be confirmed with the sponsor before launch.

## What we're asking of a faculty sponsor
- **Vet content** for one or more modules (sign-off tracked per item).
- Lend the project **departmental legitimacy** and help map curriculum anchors.
- Advise on the **pre/post-test items** and the IRB/education-exemption pathway.
- Support **continuity**: a named student successor each year so the tool stays current.

## Status

- Format proven end-to-end: recall cards, cases, red-flag reference, labeled diagram, spaced-repetition scheduling.
- **Next:** faculty content review → finalize pre/post-test → pilot with the next rotation cohort.
