The **cross-cutting core** for the ENT rotation: exam & skills, investigations, an *approach-to* framework for every cardinal complaint, all ENT emergencies/red flags, and the six-competency items. Disease-specific depth lives in the subspecialty tracks (Otology, Rhinology, …).

**Scope source:** UK undergraduate ENT Delphi (Lloyd 2014), AAO-HNS medical-student curriculum, OHSU otolaryngology medical-student curriculum. **Tags:** ACGME Otolaryngology Milestones 2.0. **Status:** all items DRAFT — pending faculty review. Check the box as each is faculty-verified.
